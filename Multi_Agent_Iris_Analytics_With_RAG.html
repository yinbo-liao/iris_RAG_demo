Main Orchestrator Agent

Role: Task planning and delegation.
Model: GPT-5 / advanced reasoning model.
Permissions: Read requests, invoke subagents, collect results.

Data Pattern Analysis Agent

Role: EDA, correlations, class separation, outlier detection.
Model: Medium model.
Permissions: Read Iris dataset and generate statistics.

Machine Learning Agents

Random Forest Agent
Train Random Forest classifier and return metrics.
SVM Agent
Train SVM classifier and return metrics.
XGBoost Agent
Train XGBoost classifier and return metrics.

Evaluation Agent

Role: Compare model performance using Accuracy, Precision, Recall, F1-score, Confusion Matrix and Cross Validation.
Model: Medium reasoning model.
Permissions: Read model outputs only.

RAG Knowledge Agent

Role: Retrieve botanical knowledge and ML explanations from vector database.
Knowledge Sources: FAISS, ChromaDB, pgvector, scientific references.
Permissions: Read-only access to vector store.

Workflow

  1. User submits Iris analysis request.
  2. Main Agent delegates EDA and model training tasks.
  3. Subagents execute in parallel.
  4. Evaluation Agent ranks models.
  5. RAG Agent enriches explanations.
  6. Main Agent produces executive summary.

Production Benefits

  • Task decomposition
  • Parallel execution
  • Least-privilege security model
  • Cost-optimized model allocation
  • Explainable AI through RAG
